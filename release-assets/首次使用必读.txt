青松口播抠像面板 v1.0.2 · 首次使用必读
========================================

三步就能出片，第一次用请按顺序来。


第 1 步：装 Python（只需装一次）
--------------------------------
本工具靠 PyTorch 跑 AI 推理，PyTorch 需要系统里有 Python 3.11。

  1) 打开 https://www.python.org/downloads/
  2) 下载 Python 3.11.x 的 Windows 64-bit 安装包
  3) 安装时【务必勾选】 "Add Python to PATH"（这一步漏了就白装）
  4) 装完关掉所有黑窗口

已经装过 Python 3.11 的，跳过这步。


第 2 步：装 GPU 依赖（只需装一次，约 2~3 GB）
--------------------------------
双击本目录下的【一键装环境.bat】，等它跑完。

  它会自动：建 .venv 虚拟环境 → 装 PyTorch CUDA 12.8 版 → 装 av/pillow/numpy
  下载量较大，网速一般要十几分钟到半小时，期间别关窗口。

也可以双击 qingsong-rvm-panel.exe，在面板里点【一键装环境】按钮，效果一样。


第 3 步：开始抠像
--------------------------------
双击【qingsong-rvm-panel.exe】

  1) 原视频：选你要抠的口播素材
  2) 背景素材：可留空（输出纯绿幕），也可选一张图片或一段视频自动合成
  3) 场景预设：口播人像选第一个就对了
  4) 模型精度：resnet50 边缘更细（推荐），mobilenetv3 更快
  5) 试跑时长：填 10 秒先看效果，满意了再改成 0 跑整条
  6) 点【开始抠像】，进度条走完即成片

右下角会显示环境状态：出现 "CUDA就绪（你的显卡型号）" 就说明一切正常。


常见问题
--------------------------------
问：为什么不直接给一个双击就能用的完整包？
答：完整的 CUDA 版 PyTorch 有 2~3 GB，全部塞进 exe 会让安装包涨到 3 GB 以上，
    而且每次启动都要解压几分钟，反而更难用。所以做成"面板秒开 + 依赖一键装"，
    装一次就永久有效，之后双击即用。

问：提示 CUDA 不可用？
答：说明装的不是 cu128 版。删掉 .venv 文件夹，重新跑一遍 一键装环境.bat。

问：NVIDIA 显卡不是 RTX 50 系也要 cu128 吗？
答：cu128 向前兼容 20/30/40 系，统一装它就行。RTX 50 系（Blackwell）必须 cu128。

问：没有 NVIDIA 显卡能用吗？
答：本版本走 GPU 推理，无独显跑不动。

问：输出的视频有声音吗？
答：有。v1.0.1 起会自动把原片的音轨合进每个 MP4（视频流不重编码，音频转 AAC），
    输出 PNG 序列时会在同目录生成同名 .m4a 原声文件，不需要再手动合音轨。

    v1.0.2 起本压缩包内已自带 ffmpeg.exe 和 ffprobe.exe，就在 qingsong-rvm-panel.exe 旁边，
    不用另装 ffmpeg、也不用配环境变量，开箱即可保留原声。
    注意别删掉或挪走这两个文件，也别把 qingsong-rvm-panel.exe 单独拷到别处使用；
    若被杀毒软件隔离，日志会提示"未找到 ffmpeg"，恢复这两个文件后重跑即可。
    查找顺序：包内目录 → 同目录下的 bin 文件夹 → LOCALAPPDATA\Programs\ffmpeg\bin、C:\ffmpeg\bin 等常见路径 → PATH。

问：输出的 MP4 没有透明通道？
答：MP4 格式本身不支持透明度。要真透明，请在面板里把输出格式选成
    "PNG 序列"，再用剪辑软件（或 ffmpeg alphamerge）合成。

问：模型权重在哪？
答：首次运行会自动下载到 rvm_repo 目录（resnet50 约 103 MB）。
